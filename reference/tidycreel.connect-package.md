# tidycreel.connect: Database and File Connections for Tidycreel

Provides connection objects and data loaders for the tidycreel creel
survey analysis package. Loads data from flat CSV files, from
DBI-compliant databases including SQL Server via ODBC, and from REST
APIs described by a caller-supplied profile.
